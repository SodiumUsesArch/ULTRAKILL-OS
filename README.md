# ULTRAKILL-OS
An arch-based linux operating system thats fully themed around the game, ULTRAKILL. 

# Notice:
This repo is still under heavy development and is currently only a setup command intended to be run on a bare arch linux system. It will eventually be turned into an installable OS with a desktop live environment so please keep that in mind 🤗

# Setup:
Boi, clone the git repo, make dat setup file executable then run it without root permission.
